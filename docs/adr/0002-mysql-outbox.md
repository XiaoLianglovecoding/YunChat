# ADR 0002: MySQL 事实源与事务 Outbox

- 状态：Accepted
- 日期：2026-08-21

## 背景

即时反馈与可靠持久化需要平衡。先写缓存再异步落库虽然延迟低，但缓存故障、进程崩溃和 MQ 发布失败会扩大数据恢复难度。

## 决策

消息主记录和 Outbox 事件在同一个 MySQL 事务内提交。Redis 只保存可以重建的派生状态。Worker 投递 RabbitMQ 时采用发布确认和至少一次语义。

## 结果

- 已确认给客户端的消息已经持久化。
- 数据库写延迟位于发送主路径，需要通过索引、批量和分区治理。
- 消费者必须用事件 ID 去重。
- Outbox 表需要定期归档。
