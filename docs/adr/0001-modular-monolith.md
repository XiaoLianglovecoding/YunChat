# ADR 0001: 以模块化单体作为起点

- 状态：Accepted
- 日期：2026-08-21

## 背景

项目由个人开发和维护，需要同时展示清晰边界与可落地性。直接拆分微服务会引入大量与聊天业务无关的部署复杂度。

## 决策

HTTP API 与 WebSocket Gateway 部署在同一 API 进程；耗时、可重试任务放在独立 Worker。代码通过领域端口隔离基础设施，为未来拆分保留边界。

## 结果

- 本地只需启动两个应用进程。
- 进程内调用简单且容易测试。
- WebSocket 独立扩容前，需要 API 实例共享在线路由信息。
- 拆分服务必须由真实容量或组织边界驱动。
